PULSE OXIMETER LAB – INTERACTIVE CLINIC SIMULATOR

Upload index.html to the root of your existing GitHub repository:
https://github.com/JacobSuber/pulse-oximeter-lab

1. Open the repository and make sure you are on the main branch.
2. Click Add file → Upload files.
3. Upload this new index.html file. It replaces the older index.html.
4. Click Commit changes.
5. Open https://jacobsuber.github.io/pulse-oximeter-lab/
6. Select 02 Practice to start the new virtual exam room.
7. If your browser shows the old version, refresh with Ctrl+Shift+R.

WHAT'S INCLUDED
- Learn: The original seven-step instructions, common mistakes, and safety notes.
- Practice: Five patient scenarios with equipment actions, hand/finger selection,
  draggable clip, simulated screen stabilization, interpretation, documentation,
  and aftercare.
- Quiz: Ten questions from the original guide.
- No API key, login, install, or external packages required.

EDUCATIONAL USE ONLY
This site generates fictional patient cases and simulated measurements. It does
not sense oxygen or pulse, establish clinical competence, give diagnoses,
or replace clinical supervision and facility protocols.
